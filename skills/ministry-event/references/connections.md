# Connections

No connection is needed. Every step works from typed answers, pasted numbers or exported files. Connections save copy-pasting and let drafts land in the ministry's own tools.

| Need | Options | How to verify | Fallback |
|---|---|---|---|
| Keep the plan and files | Cowork reading and writing the event folder (a synced shared drive folder works); a Google Drive or similar connector if connected | Save the profile and confirm the user can see it | Drafts in chat to copy into their documents |
| Registrations | The registration tool's export (for example Planning Center Registrations, Eventbrite, Google Forms or Jotform); a connector if one is connected | Read the column headers and row count back to the user | CSV or spreadsheet export with only the needed columns; or the counts typed in |
| Payments | Your payment processor, usually through the registration tool's export | Totals match the registration tool | Counts of paid registrations typed in |
| Survey | The form tool's export; per-response notification emails to the organizer if the tool offers them | Read headers and row count; match one known registrant | Paste responses |
| Email drafts | The ministry's email platform (for example Mailchimp or Constant Contact), or a Gmail or Outlook connector, if connected | Create one draft only when asked; confirm where it is; never send | Draft text in chat |
| Calendar | A calendar connector, if connected | Create a checkpoint reminder only when asked; read it back | A list of checkpoint dates in `HANDOFF.md` |
| Actual costs | QuickBooks Online, if connected | Read one known expense back | Receipts or a cost list typed in |

Discover what is actually connected at runtime; names differ between setups. Never claim a connector exists or works until you have used it. Never ask for passwords or keys in chat. Social posts are always drafts; a person posts them.

## Recovery

- Export has more columns than needed: tell the user which to delete, or ignore them and don't repeat personal details back.
- Numbers don't match between tools: show both totals and ask which is the source of truth.
- A survey response won't match: list it as unmatched; don't guess who it is.
- A draft was created in the wrong list or account: tell the user right away; don't send, delete or change anything yourself.
- New teammate, new chat or new computer: read the profile and `HANDOFF.md` first, then say where things stand and the next checkpoint.
