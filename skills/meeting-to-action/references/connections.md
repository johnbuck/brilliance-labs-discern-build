# Connections

No connection is needed. Pasted notes, an uploaded file or a phone photo are enough. Connections only save copy-pasting and let drafts land where the ministry already works.

| Need | Options | How to verify | Fallback |
|---|---|---|---|
| Get the notes | Cowork reading the meetings folder; a connector for the note or recording tool if one is connected (for example Zoom, Teams, Otter or Granola); a Google Drive or similar connector | Find this meeting by date and title and read its first lines back to the user | Export the transcript or notes (.txt, .docx, .vtt or PDF), upload, or paste |
| Handwritten notes | A clear phone photo, one page per image | Transcribe one page and have the user compare | The user types the key lines |
| Save drafts | Cowork writing to the chosen folder; a document connector if connected | Save the profile or a test file and confirm the user can see it | Give drafts in chat to copy into Word or a Google Doc |
| Email follow-ups | A Gmail or Outlook connector, drafts only, if connected | Create one draft to the user only, if they ask, and confirm they see it | Draft text in chat, ready to copy |
| Action items | A shared spreadsheet, or a task tool if connected | Read the sheet's headers or one task back | `open-actions.md` in the folder, or a table in chat |

Discover what is actually connected at runtime; names differ between setups. Never claim a connector exists or works until you have used it. A connected note tool may hold many meetings, including pastoral ones: open only the meeting the user names. Never ask for passwords or keys in chat.

Recording meetings: some places require everyone's consent to record. If the user asks, suggest they check their own rules and bylaws; don't give legal advice.

## Recovery

- Transcript cut off or missing a section: say where it stops. Don't fill gaps from the agenda; mark those items "[not in notes: confirm]".
- Speaker labels look wrong: flag every motion or vote whose speaker is uncertain and ask the user.
- Two sources disagree (notes versus transcript): show both lines and ask which is right.
- A held-out item appears in a draft: remove it, tell the user where it was, and re-check all three drafts.
- An email draft was created in the wrong account or to the wrong people: tell the user right away; don't delete or send anything yourself.
- New secretary, new chat or new computer: read the profile and `open-actions.md` first, then say where things stand.
