# Recovery prompts and actions

| User situation | Guided response | Verification before continuing |
| --- | --- | --- |
| Logos is not connecting | “Let’s check the signed-in window and the available browser tool. Are you seeing your library or a sign-in screen?” | Observe the actual library. If unavailable, use permitted source notes and label the route |
| I do not own that book | “We’ll remove it from this run. Which relevant resources can you open?” | Verify alternatives, update the resource access record, and disclose the substitution |
| My library is small | “We can work with the sources you have and make that limited source base clear.” | One source supports a source summary, not a consensus claim |
| The extract stops early | “This source is partial. We’ll retrieve the missing section or preserve the limitation.” | Check the requested opening and ending. Import a new source record only after correction |
| I added books | “Let’s verify the new resources and add them to your shelf.” | Open the new book under the active account and register it |
| My account changed | “We’ll create a separate workspace for this account.” | Fresh profile, resource checks, and source records. Do not reuse the previous profile’s sources |
| I changed computers | “We’ll reconnect Logos and check the local tools on this computer.” | Verify runtime and host tools. Use source notes if browser control is unavailable |
| I want a sermon manuscript | “This skill covers research and exegesis. We can continue reviewing the research here.” | Do not silently expand the skill’s scope |

If a source changes or disappears, mark its resource record unavailable/unverified. The packet builder will reject that source until access is reverified. Existing saved outputs remain historical artifacts, not proof of current access.
